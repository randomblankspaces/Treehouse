# Treehouse public judge note

This document is owned project demonstration material, prepared for the Treehouse
AWS challenge. It contains public project facts, not field observations, private
imagery, benchmark answers, medical information or measurements of real people.

## Distinctive project fact

Treehouse's judge demonstration marker is **Cedar Lantern 47**. The marker names
the three-step evidence walk: owned source, actual Gateway tool call, live Runtime
answer. It is a mnemonic created for this project, not a measured scientific result.

## The three demonstration tasks

Know Your Stuff: ingest this public note into an Amazon Bedrock Knowledge Base,
then answer a question with a citation to the ingested source.

Gateway Builder: publish search_project_docs, list_task_cards and explain_rule as
three MCP tools on an Amazon Bedrock AgentCore Gateway. A Strands agent must
actually invoke a Gateway tool; listing tool definitions alone proves no call.

Ship It: host that agent on AgentCore Runtime and obtain an answer from the live
IAM-authenticated endpoint. Retain the real request ID and resource identifiers.

## Evidence rules

Simulation results are not physical measurements. An offline test does not prove
AWS deployment, real-world optical performance, comfort, tracking, battery life,
heat, radio performance or latency. A recorded receipt shows a past observation;
it must not be relabeled as a new live invocation.

The project does not yet settle the first user scenario, hardware or runtime.
Spatial 3D content and a desktop simulator remain ideas to test.

## Privacy and budget

Ingest only this public note. Do not ingest private imagery, location records,
answer keys, credentials or recordings of other people. Do not log prompts.

The new challenge path has a $15 working budget and a $25 stop threshold.
Existing account guards remain $350 warning and $450 hard stop. Billing is delayed;
these numbers are decision thresholds, not a claim that AWS enforces a hard cap.
